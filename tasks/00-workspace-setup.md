# Workspace setup

[Back to task index](../TASKS.md)

- [ ] Measure the working footprint and determine how much of the workshop floor needs protection
- [ ] Lay plywood sheets over the workshop floor before moving the boat in
- [ ] Secure or bridge plywood seams and protect exposed edges so sheets cannot shift or become trip hazards
- [ ] Decide on a controlled method for transferring the boat between the trailer and workshop supports
- [ ] Rig the lifting / rolling system needed to get the boat safely off and back onto the trailer
- [ ] Evaluate using the beach rollers as part of the trailer-to-shop transfer
- [ ] Prepare padded cribbing, stands, or other stable supports for the boat once it is off the trailer
- [ ] Verify any lifting or attachment points and supporting structure are suitable for the expected loads
- [ ] Do a dry run of the transfer path and make sure the reverse process for loading the trailer is practical
